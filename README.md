# CGPA Calculator Web App

A simple Flask-based web application that calculates SGPA and CGPA for students based on subject grades and credits.

## Features

- Input semester and subject details
- Compute SGPA for current semester
- Calculate CGPA from previous semesters
- Clean and user-friendly interface

## 🛠️ Tech Stack

- Python (Flask)
- HTML, CSS, JavaScript
- SQLite (for storing data)
